## 📖 Overview

DataPilot AI is an end-to-end Business Intelligence application built with Python and Streamlit. It enables users to upload datasets, clean data, perform exploratory analysis, visualize insights, train machine learning models, and export professional reports.

## ✨ Features

- 📁 Upload CSV datasets
- 🧹 Data Cleaning
- 📊 Interactive Dashboard
- 📈 Advanced Analytics
- 🤖 Machine Learning
- 📄 PDF, CSV & Excel Export

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- Scikit-Learn
- Statsmodels
- ReportLab
- OpenPyXL

## 🚀 Installation

```bash
git clone https://github.com/ayushmishra2406/DataPilot-AI.git
cd DataPilot-AI

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

streamlit run app/main.py
```
